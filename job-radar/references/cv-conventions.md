# CV and cover-letter conventions by market

Use the row for the job's country; if none fits, the candidate's `cv_style`; else **INTL**. These are norms, not laws: the truth rules in SKILL.md always win, and personal data is only ever taken from the profile. If a convention expects data the profile lacks (photo, date of birth), say so in the notes - never invent it.

## General rules for every market

- Reverse chronological order unless the candidate asks otherwise.
- Contact details exactly as in `application` (or the resume header).
- Reformat dates to the convention, never change them.
- Translate section headings when the document language changes; never translate company names, product names or certificate names.
- For a non-English document, keep tool and technology names in their usual (often English) form.
- If the posting asks for a specific format (e.g. Europass, a portal's own form), mention it in the notes rather than switching format unasked.
